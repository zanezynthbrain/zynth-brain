# Staging, AV & Build — materials, methods, vocabulary

## Structures
- **Truss** — aluminium lattice (290/390mm box common). Carries lights, LED,
  speakers. Ground-supported (goalpost, box) vs **rigged** (hung from venue
  points — needs venue's rigging plot + load ratings; many Yangon ballrooms
  have NO rated rigging points → ground support, which eats floor space).
- **Modular staging** — decked platforms (1×2m, 4ft×8ft), adjustable legs
  0.4–1.2m. Ask: rated load (kg/sqm), skirting, stairs with handrail.
- **Custom build / carpentry** — MDF+timber scenic fronts, CNC logos.
  Yangon strength: cheap skilled carpentry. Weakness: fire-rating, finish
  consistency — inspect at workshop BEFORE load-in day.
- **Sustainable trend (SG standard, coming here):** modular re-use systems,
  fabric prints over PVC, rental furniture over build-and-burn. SG clients
  now ask "what happens to this after the event?" — have an answer.

## LED & projection
- **LED pixel pitch** = distance between pixels. P2.6 (indoor premium,
  viewers <5m), P3.9 (standard indoor), P4.8+ (outdoor/distance). Smaller
  pitch = sharper = pricier. Rule: pitch ≈ minimum viewing distance in metres.
- Ask LED vendors: pitch, panel brand/age, processor (Novastar?), spare
  panels on site, tech on standby.
- **Projection**: needs throw distance + control of ambient light —
  ballroom chandeliers kill projection; LED wins despite cost.

## Sound & power
- Speeches only: distributed small PA. Live band/DJ: line array + subs +
  monitor wedges + experienced FOH engineer (the invisible line item that
  saves the night).
- **Power**: hotel house power vs generator. Outdoor = generator + backup +
  cabling ramps. Ask total kW of LED+sound+lights BEFORE quoting; generator
  fuel + standby operator is a real line item people forget.

## The five questions that expose a weak AV quote
1. What's the pixel pitch and panel age?
2. Where is the rigging plot / is this ground-supported?
3. How many crew on show day, and who is the FOH engineer?
4. What's the backup for main console / media server?
5. Load-in hours assumed — and the overtime rate after that?
