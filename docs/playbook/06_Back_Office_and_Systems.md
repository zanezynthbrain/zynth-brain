# 💰 PILLAR 1 — FINANCE

## 1.1 — The Cash Flow Engine (အရေးအကြီးဆုံး)

**Profit ≠ Cash.** ဒါကို နားလည်ပါ။

```
ဥပမာ:
  Jan — SGD 100K project ရတယ်။ Profit SGD 40K ✅
  Jan — Vendor ကို SGD 40K ပေးရတယ် (ချက်ချင်း)
  Jan — Staff လစာ SGD 25K ပေးရတယ်
  Mar — Client က SGD 100K ပေးတယ် (60 ရက်နောက်ကျ)

  ဒါဆို Jan–Feb မှာ မင်း SGD 65K လိုနေတယ်။
  Profit ရှိပေမယ့် — CASH မရှိလို့ သေမယ်။ ⚠️
```

### The 13-Week Rolling Cash Forecast (တစ်ပတ်တစ်ခါ update)

| Week | Cash In (Expected) | Cash Out | Net | Running Balance |
|---|---|---|---|---|
| W1 | Deposits, invoices due | Payroll, vendors, rent | | |
| W2 | ... | ... | | |
| ... | | | | |
| W13 | | | | ⚠️ ဘယ်ပတ်မှာ အနီရောင်ဝင်လဲ? |

> **ဒီ spreadsheet တစ်ခုက မင်းရဲ့ business ကို ကယ်တင်နိုင်တယ်။** Excel/Sheets မှာ လုပ်ပါ။ ရှုပ်စရာမလိုဘူး။

## 1.2 — Invoicing Discipline (ဒါက ရိုးရှင်းပေမယ့် အများစု မလုပ်ဘူး)

```
RULE 1  Milestone ရောက်တာနဲ့ ၂၄ နာရီအတွင်း invoice ထုတ်
RULE 2  Invoice က automatic ဖြစ်ရမယ် (calendar reminder / accounting software)
RULE 3  Payment terms: Net 15 or Net 30. Net 60 ကို လက်မခံနဲ့။
RULE 4  Late fee ကို contract မှာ ရေးထား (1.5%/month)
RULE 5  Deposit မရဘဲ အလုပ်မစရ — ခြွင်းချက် မရှိ ✅
```

### The Collections Ladder (ငွေမရရင် ဘယ်လိုလုပ်မလဲ)
```
Day 0    Invoice sent
Day -3   Friendly reminder BEFORE due date ("just a heads up")
Day +1   Polite follow-up email
Day +7   Phone call (email မဟုတ်ဘူး — ဖုန်းဆက်)
Day +14  Escalate to their finance dept + your AM
Day +21  Formal letter, work paused notification ⚠️
Day +30  Stop work. Legal notice.
```
> **လူကြီးလူကောင်း ဆက်ဆံရေးကို ကြောက်ပြီး ငွေမတောင်းရင် — မင်း charity လုပ်နေတာ။**
> ငွေတောင်းတာက **အရှက်ရစရာ မဟုတ်ဘူး**။ Business ပါ။

# 👥 PILLAR 2 — PEOPLE / HR

## 2.1 — Hiring SOP

```
STEP 1  Scorecard အရင်ရေး — role ရဲ့ mission + 3–5 KPI (JD မဟုတ်ဘူး)
STEP 2  Sourcing — network > job board (referral bonus ပေး)
STEP 3  Screen — 20 min call, culture + basics
STEP 4  Skills test — PAID test task ✅ (အခမဲ့ မခိုင်းနဲ့ — reputation ပျက်တယ်)
STEP 5  Panel interview — 2 people minimum
STEP 6  Reference check — ဖုန်းဆက်၊ email မဟုတ်ဘူး
STEP 7  Offer + contract
STEP 8  Onboarding (below)
```

### The 30-Day Onboarding Plan
```
DAY 1     Tools, access, buddy assigned, ZYNTH story & values
WEEK 1    Shadow. Read all SOPs. Meet every team member.
WEEK 2    First real task (small, supervised). Scorecard walkthrough.
WEEK 3    Own a small deliverable end-to-end.
WEEK 4    30-day review — fit check. သဘောမတူရင် ဒီမှာ ရပ်။
DAY 90    Full review — confirm or exit
```
> **Hire slow, fire fast.** ZYNTH လို team သေးသေးမှာ — မကောင်းတဲ့ hire တစ်ယောက်က team တစ်ခုလုံးရဲ့ standard ကို ဆွဲချတယ်။

## 2.2 — Compensation Structure
```
BASE SALARY       Market rate (SG: benchmark on MyCareersFuture / Glassdoor)
PERFORMANCE BONUS 10–20% of base, tied to individual scorecard
PROFIT SHARE      5–10% of net profit pool, split by contribution (Year 2+)
COMMISSION        BD: 5–10% of first-year revenue closed
                  AM: 3–5% of upsell revenue ✅ (ဒါက upsell culture ဖန်တီးတယ်)
```

## 2.3 — Retention (agency မှာ turnover မြင့်တယ် — ဒါကို ဖြေရှင်း)
```
☐ Monthly 1:1 (30 min) — မဖျက်ရ
☐ Clear career path — "ငါ ဘယ်လို promote ဖြစ်မလဲ" ဆိုတာ သိရမယ်
☐ Learning budget (SGD 500–1,500/year per person)
☐ No-burnout policy — utilization > 85% က red flag
☐ Public recognition — Friday wins session
☐ Portfolio ownership — သူတို့ရဲ့ work ကို credit ပေး
```
> **Creative လူတွေက ငွေအတွက်ပဲ အလုပ်လုပ်တာ မဟုတ်ဘူး။ သူတို့က *ဂုဏ်ယူစရာ work* အတွက် လုပ်တာ။**
> ညံ့တဲ့ client + ညံ့တဲ့ brief ပေးရင် — အကောင်းဆုံး လူတွေ ထွက်သွားမယ်။

# ⚖️ PILLAR 3 — LEGAL & CONTRACTS

## 3.1 — Documents မဖြစ်မနေလိုတဲ့ စာရွက်တွေ

| Document | ဘာအတွက် |
|---|---|
| **Master Services Agreement (MSA)** | Client နဲ့ ရေရှည် ဆက်ဆံရေး framework |
| **Statement of Work (SOW)** | Project တိုင်း — ဘာလုပ်မလဲ၊ ဘယ်လောက်လဲ၊ ဘယ်တော့လဲ |
| **Change Order** | Scope ပြောင်းရင် တိုင်း ✅ |
| **NDA** | Pitch မလုပ်ခင် |
| **Freelancer Agreement** | IP transfer clause ပါရမယ် ⚠️ |
| **Talent / Model Release** | Video/photo shoot တိုင်း |
| **Vendor Agreement** | Deliverable, timeline, penalty |
| **Employment Contract** | SG: MOM compliant |

## 3.2 — SOW ထဲမှာ မဖြစ်မနေ ပါရမယ့် Clause

```
✅ DELIVERABLES — အတိအကျ (ဥပမာ: "12 social posts" ✅ not "social content" ❌)
✅ EXCLUSIONS — ဘာမပါဘူးလဲ ← ဒါက scope creep ကို တားတဲ့ အကာအကွယ်
✅ REVISION ROUNDS — "2 rounds included, additional at SGD X"
✅ TIMELINE — client ရဲ့ feedback အချိန်ပါ ထည့်ရေး ("2 business days")
✅ CLIENT DEPENDENCIES — "If client feedback is delayed, timeline shifts accordingly"
✅ PAYMENT TERMS + LATE FEE
✅ IP OWNERSHIP — "IP transfers upon FULL payment" ⚠️ အရေးကြီး
✅ USAGE RIGHTS — media, territory, duration (video/photo အတွက်)
✅ KILL FEE — cancel လုပ်ရင် ဘယ်လောက်ပေးရမလဲ
✅ APPROVER — single named person
✅ FORCE MAJEURE
```

> ⚠️ **"IP transfers upon full payment"** — ဒီ စာကြောင်းတစ်ကြောင်းက မင်းရဲ့ အကောင်းဆုံး ငွေတောင်းတဲ့ လက်နက် ဖြစ်တယ်။ မပေးရင် — သူတို့ က ဒီ asset ကို တရားဝင် သုံးလို့မရဘူး။

## 3.3 — Scope Creep Defence

```
Client: "ဒါလေး တစ်ခုပဲ ထပ်လုပ်ပေးလို့ရမလား?"

❌ WRONG:  "ရပါတယ် ရပါတယ်" → margin သေတယ်
✅ RIGHT:  "ရပါတယ်။ ဒါက SOW ထဲမှာ မပါလို့ change order တစ်ခု ပို့ပေးမယ်။
            Timeline မှာ ၂ ရက် ထပ်လိုမယ်၊ fee က SGD X ဖြစ်မယ်။
            လုပ်လိုက်ရမလား?"
```
Client ရဲ့ 70% က "ဒါဆို နေပါစေ" လို့ ပြောလိမ့်မယ် — ဆိုလိုတာက **သူတို့ တကယ် မလိုဘူး**။
ကျန် 30% က ပေးလိမ့်မယ် — အဲဒါက **revenue အသစ်** ✅
