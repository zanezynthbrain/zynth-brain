# 05 — STANDARD OPERATING PROCEDURES
## Service Line တိုင်းရဲ့ End-to-End Process

---

## SOP ရဲ့ အခြေခံ

> **SOP မရှိရင် — မင်းက agency မဟုတ်ဘူး၊ လူတစ်စု စုပြီး ခန့်မှန်းနေတာပဲ။**

SOP ရဲ့ စစ်ဆေးမှု (The SOP Test):
> **"အသစ်ဝင်လာတဲ့လူတစ်ယောက်က ဒီ document ဖတ်ပြီး တစ်ယောက်မှ မမေးဘဲ အလုပ်လုပ်လို့ရလား?"**
> မရရင် — ဒါ SOP မဟုတ်ဘူး၊ note ပဲ။

---

# 🌐 THE UNIVERSAL SOP (Service အားလုံးအတွက် အခြေခံ)

```
STAGE 0 — QUALIFY          ဒီအလုပ်ကို လက်ခံသင့်လား?
STAGE 1 — BRIEF            ဘာလုပ်ရမလဲ တိတိကျကျ
STAGE 2 — SCOPE & PRICE    ဘာပါလဲ၊ ဘာမပါဘူးလဲ၊ ဘယ်လောက်လဲ
STAGE 3 — CONTRACT         SOW + deposit ✅ (ဒါမရဘဲ Stage 4 မသွားရ)
STAGE 4 — KICKOFF          Team briefed, timeline live
STAGE 5 — PRODUCE          SOP အတိုင်း ထုတ်လုပ်
STAGE 6 — INTERNAL QC      Client မမြင်ခင် ZYNTH က စစ်
STAGE 7 — CLIENT REVIEW    Max 2 revision rounds
STAGE 8 — DELIVER          Final assets + handover
STAGE 9 — MEASURE          Result ကို data နဲ့ ပြ
STAGE 10 — EXPAND          Upsell / referral / case study
```

**ဘယ်တော့မှ ချိုးဖောက်လို့မရတဲ့ ၃ ချက်:**
1. **Deposit မရဘဲ အလုပ်မစရ။** (Stage 3 gate)
2. **Internal QC မဖြတ်ဘဲ client ဆီ ဘာမှ မပို့ရ။** (Stage 6 gate)
3. **Stage 9 & 10 ကို မကျော်ရ။** (ဒါက ငွေရှိတဲ့နေရာ)

# 🎬 SOP 1 — VIDEO PRODUCTION

## PHASE 1: PRE-PRODUCTION (60% of success)

### Step 1.1 — Creative Brief (Day 1–2)
```
☐ Client objective — ဘာအတွက် ဒီ video လုပ်တာလဲ?
☐ Target audience — ဘယ်သူကြည့်မလဲ?
☐ Key message — တစ်ကြောင်းတည်း
☐ Call to action — ကြည့်ပြီးရင် ဘာလုပ်စေချင်လဲ?
☐ Platform & specs — TikTok 9:16? YouTube 16:9? Both?
☐ Duration
☐ Mandatories — logo, tagline, legal, product shots
☐ Tone & reference — ဥပမာ video 3 ခု
☐ Budget & timeline
☐ Approver — ဘယ်သူက final yes ပြောလဲ? (တစ်ယောက်တည်း ဖြစ်ရမယ်)
```
> ⚠️ **Approver အယောက် ၂၀ ရှိရင် — project က သေပြီ။** Contract မှာ **single approver** ကို ရေးထည့်ပါ။

### Step 1.2 — Concept & Script (Day 3–7)
```
☐ Concept territories — 2–3 ခု ပေး (တစ်ခုတည်း မပေးနဲ့)
☐ Internal creative review (CD sign-off)
☐ Present to client
☐ Client selects → script written
☐ Script approved IN WRITING ✅
```

### Step 1.3 — Pre-Production Package (Day 8–14)
```
☐ Storyboard / shot list (ဒါမရှိရင် shoot day မှာ ငွေဖျင်းမယ်)
☐ Shooting schedule / call sheet
☐ Location recce + permits
☐ Talent casting + release forms
☐ Crew booked & confirmed (written confirmation)
☐ Equipment list + rental booked
☐ Wardrobe, props, art department
☐ Catering & transport
☐ Contingency plan (မိုးရွာရင်? Talent မလာရင်?)
☐ PPM (Pre-Production Meeting) with client — ဒါက အရေးကြီးတယ်
```
> **PPM ရဲ့ ရည်ရွယ်ချက်:** Shoot day မတိုင်ခင် **surprise အားလုံးကို ကုန်စေ**ဖို့။
> PPM မှာ client က "အင်း၊ ဒါပဲ" လို့ ပြောပြီးရင် — shoot day မှာ ပြောင်းလို့မရတော့ဘူး (change order လိုမယ်)။

## PHASE 2: PRODUCTION (Shoot Day)

```
☐ Crew call — 30 min early, brief everyone
☐ Shot list ကို visible နေရာမှာ ချိတ်
☐ Producer က shot list ကို tick လုပ်တယ် (ဘယ်ဟာရပြီးလဲ)
☐ Client on set? → သူ့အတွက် monitor + chair + ရေ ပေး (small thing, big impact)
☐ Data wrangler — footage ကို 2 backup ချက်ချင်းလုပ် ✅
☐ Behind-the-scenes content ရိုက် (bonus deliverable — client ကြိုက်တယ်)
☐ Wrap — gear check, release forms signed, location cleared
☐ Client ကို same-day thank you + BTS teaser ပို့ ✅
```
> **Golden rule:** Footage ကို backup ၂ ခု မလုပ်ဘဲ set မကျော်ရ။ Card တစ်ခု ပျက်ရင် — project တစ်ခုလုံး သေတယ်၊ reputation ပါ သေတယ်။

## PHASE 3: POST-PRODUCTION

```
☐ Ingest + organize footage (naming convention)
☐ Rough cut (V1) — internal review
☐ CD review + notes
☐ Client review V1 → consolidated notes (တစ်စောင်တည်း၊ WhatsApp ၅ ခု မဟုတ်ဘူး)
☐ V2 — colour, sound design, music, graphics
☐ Client review V2 → final notes only
☐ V3 FINAL — master render
☐ Deliverables: master + platform cuts (9:16, 1:1, 16:9) + captions/subtitles
☐ Upload to client drive + archive to ZYNTH library
☐ Post-delivery: performance check after 2 weeks ✅
```

**Revision policy (contract မှာ ရေးထား):**
```
2 revision rounds included.
Round 3+ = SGD [X] per round.
"Revision" = notes ကို တစ်စောင်တည်း စုပေးတာ။ Piecemeal notes = new round.
```

# 🎪 SOP 2 — EVENT MANAGEMENT

## PHASE 1: PRE-EVENT (T-minus 8 weeks → Event Day)

### T-8 to T-6 Weeks: Concept & Contract
```
☐ Client brief — objective, audience, budget, date, guest count
☐ Event concept + theme developed
☐ Creative deck: concept, mood, spatial design, 3D render (VERA/Blender) ✅
☐ Budget built (line by line — venue, F&B, AV, decor, talent, manpower, contingency 10%)
☐ Proposal presented — 3 options (Essential / Recommended / Premium)
☐ Contract signed + 50% deposit received ✅ ← GATE
```

### T-6 to T-4 Weeks: Lock the Foundation
```
☐ Venue booked + contract signed
☐ Date locked, permits applied
☐ Vendor RFQs sent (min. 3 quotes per category)
☐ Vendor selected + deposits paid (client deposit ရပြီးမှသာ)
☐ Run of show V1 drafted
☐ Marketing plan activated (if public event)
☐ Registration system live
☐ Talent / emcee / performers booked
```

### T-4 to T-2 Weeks: Build
```
☐ All creative assets produced (backdrop, signage, collateral, digital)
☐ Client approval on all designs
☐ Production drawings sent to fabricator
☐ AV tech spec finalised + tested
☐ F&B menu confirmed + dietary requirements
☐ Manpower roster built (names, roles, call times, uniforms)
☐ Guest list managed, invites sent, RSVPs tracked
☐ Run of show V2 — minute by minute
☐ Contingency plan documented (rain / power / VIP late / no-show / medical)
```

### T-2 Weeks to T-0: Final
```
☐ Final headcount to venue & caterer (usually T-72 hours)
☐ Site visit + walkthrough with all vendors
☐ Rehearsal (emcee, speakers, AV cues, entertainment)
☐ Final run of show distributed to EVERYONE
☐ Crew briefing pack: map, contacts, roles, timings, emergency numbers
☐ Emergency contact sheet — printed, laminated, on every crew member
☐ Balance payment invoice issued (T-7 days) ✅
☐ Load-in schedule confirmed
```

## PHASE 2: EVENT DAY

```
LOAD-IN
☐ Crew arrives per call sheet
☐ Vendor check-in (tick against list)
☐ Setup per floor plan
☐ AV test — sound, lights, screens, mics (test EVERY mic)
☐ Photo/video crew briefed on must-get shots
☐ Registration desk set + tested
☐ Green room ready

SHOWTIME
☐ Event Manager = single point of command (radio/WhatsApp group)
☐ Run of show ကို လိုက်နာ — 5 min buffer per segment
☐ Photographer/videographer capture per shot list
☐ Live social content posted (real-time)
☐ Client handled — someone assigned ONLY to the client ✅
☐ Issues logged (not solved in front of client)

LOAD-OUT
☐ Vendor sign-off (damage check)
☐ Client items returned
☐ Venue cleared per contract
☐ Equipment reconciled
```

> **အရေးကြီးဆုံး role: "Client Handler".** Event day မှာ client က စိုးရိမ်တယ်။ တစ်ယောက်ကို **client နဲ့ပဲ နေခိုင်း**ပါ — ရေပေး၊ ရှင်းပြ၊ စိတ်အေးအောင်လုပ်။ ဒါက event ရဲ့ perception ကို 50% ဆုံးဖြတ်တယ်။

## PHASE 3: POST-EVENT (⚠️ အများစု ကျရှုံးတဲ့နေရာ)

```
T+24 hours
☐ Thank you message to client + team + vendors
☐ Teaser content posted (photo highlights)

T+3 days
☐ Full photo gallery delivered
☐ Attendee survey sent

T+7 days ← DEADLINE ✅
☐ Highlight video delivered
☐ POST-EVENT REPORT delivered:
     - Attendance vs target
     - Engagement metrics (social reach, hashtag, media coverage)
     - Attendee satisfaction score
     - Budget: quoted vs actual
     - Photo/video assets
     - What worked / what to improve
     - **RECOMMENDATION FOR NEXT EVENT** ← ဒါက upsell ✅

T+14 days
☐ Vendor settlement complete
☐ Final invoice issued
☐ Internal debrief — learnings documented
☐ Case study drafted
☐ Client debrief call → next opportunity discussed
```

# 🎨 SOP 3 — DESIGN & CREATIVE CONCEPT

```
STEP 1 — CREATIVE BRIEF (client + AM + CD)
   ☐ Business problem (not "we need a poster")
   ☐ Audience insight — ဘာကို ဂရုစိုက်လဲ?
   ☐ Single-minded proposition
   ☐ Mandatories & restrictions
   ☐ Success criteria

STEP 2 — RESEARCH & INSIGHT (1–3 days)
   ☐ Category audit — competitor တွေ ဘာလုပ်နေလဲ?
   ☐ Cultural / market context (SG vs MM ကွာတယ်)
   ☐ Insight statement — "We noticed that..."

STEP 3 — CONCEPT DEVELOPMENT (3–5 days)
   ☐ 3 territories developed (not 1, not 10)
   ☐ Each territory: idea + rationale + key visual + how it lives across channels
   ☐ Internal CD review — "Is it distinctive? Defensible? Strategic?"
   ☐ Weak territory ကို ဖျက်ပစ် — client ကို မပြနဲ့

STEP 4 — PRESENT (not "send")
   ☐ Present live — story ပြောပြ
   ☐ Recommendation ပေး ("We recommend Territory B, because...")
   ☐ Client feedback ကို live မှာ ယူ

STEP 5 — REFINE & EXECUTE
   ☐ Chosen territory → full toolkit
   ☐ Master artwork → adaptations (all sizes, all channels)
   ☐ Internal QC (spelling, brand, specs, colour profile)
   ☐ Client approval
   ☐ Package + handover (source files + guidelines)
```

**Internal QC Checklist (client ဆီ မပို့ခင် တိုင်း):**
```
☐ Spelling & grammar (မြန်မာ + English နှစ်ခုလုံး)
☐ Brand colours correct (hex/CMYK)
☐ Logo — correct version, clear space, min size
☐ Specs correct (dimensions, bleed, resolution, colour profile)
☐ Legal / disclaimers present
☐ Client name spelled correctly 😅 (ဒါက အမြဲဖြစ်တယ်)
☐ File naming convention followed
☐ Does it answer the brief? ← အရေးအကြီးဆုံး
```

# 📱 SOP 4 — META / TIKTOK PAID MEDIA

## SETUP PHASE (One-time — charge a setup fee)
```
☐ Business Manager access (Admin, not Employee)
☐ Ad account + payment method
☐ Pixel installed + verified
☐ Conversions API (CAPI) configured ← ဒါက iOS ကြောင့် မဖြစ်မနေလိုတယ်
☐ Domain verified
☐ Events configured & prioritized (Aggregated Event Measurement)
☐ Audiences built: custom, lookalike, retargeting, exclusion
☐ UTM taxonomy defined & documented
☐ GA4 linked
☐ Naming convention: [Client]_[Objective]_[Audience]_[Creative]_[Date]
```

## CAMPAIGN STRUCTURE (The Standard Build)
```
CAMPAIGN (Objective: Conversions)
├── AD SET 1 — Cold: Interest/Broad
│     ├── Ad A (Hook 1 × Angle 1)
│     ├── Ad B (Hook 2 × Angle 1)
│     └── Ad C (Hook 3 × Angle 1)
├── AD SET 2 — Cold: Lookalike 1–3%
│     └── [same 3 creatives]
└── AD SET 3 — Warm: Retargeting (site visitors, engagers, video viewers 50%+)
      └── [different creative — offer/urgency]
```

## WEEKLY OPTIMIZATION LOOP
```
MON   ☐ Weekend spend + performance review
      ☐ Kill ads below threshold (CTR < 0.8%, CPA > 150% target)
      ☐ Scale winners (+20% budget max per day — မလွန်နဲ့)
TUE   ☐ Launch new creative tests
WED   ☐ Audience performance review — ဘယ် audience က ကောင်းလဲ
THU   ☐ Landing page / funnel check (drop-off ဘယ်မှာလဲ?)
FRI   ☐ Weekly report + client update
```

**Creative Testing Rule:**
> **Ad က မကောင်းရင် — algorithm ကို မအပြစ်တင်နဲ့။ Creative ကို ပြောင်း။**
> Performance ရဲ့ 70% က **creative** ကနေ လာတယ်။ 20% က audience။ 10% ပဲ bidding/setup။
> ဒါကြောင့် ZYNTH မှာ **creative team နဲ့ media team က တွဲလုပ်ရမယ်** — သီးသန့် မဟုတ်ဘူး။ ဒါက ZYNTH ရဲ့ integrated advantage ပါ။

## SCALING RULES
```
☐ Winner = 3+ days consistent performance, min 50 conversions
☐ Scale: +20% budget every 2–3 days (မဟုတ်ရင် learning phase ပြန်ဝင်မယ်)
☐ Horizontal scale: duplicate to new audience (safer than vertical)
☐ Never touch a winning ad set မလိုအပ်ဘဲ
☐ Budget cap alerts set (overspend = ZYNTH ကနေ ပြန်ပေးရမယ် ⚠️)
```

# 🔍 SOP 5 — SEO / SEM

## SEO — Month 1: Audit & Foundation
```
☐ Technical audit — crawl, index, speed, mobile, schema, broken links
☐ Keyword research — volume, difficulty, intent, competitor gap
☐ Content audit — ဘယ် page က rank ဝင်နေလဲ? ဘယ်ဟာ dead လဲ?
☐ Backlink profile audit
☐ Competitor gap analysis — သူတို့ rank ဝင်ပြီး ငါတို့ မဝင်တဲ့ keyword
☐ Priority action list — Quick wins vs Strategic
```

## SEO — Ongoing Monthly Loop
```
WEEK 1  ☐ Rank tracking review + report
        ☐ Technical health check
WEEK 2  ☐ Content briefs written (4–8 pieces)
        ☐ On-page optimization (title, meta, H1, internal links)
WEEK 3  ☐ Content published
        ☐ Backlink outreach (5–10 targets)
WEEK 4  ☐ Performance analysis
        ☐ Next month priorities
        ☐ Client report + call
```

## SEM (Google Ads)
```
☐ Account structure: Campaign → Ad Group (tight themes, 5–15 keywords)
☐ Match types: Exact + Phrase (Broad only with smart bidding + strong data)
☐ Negative keyword list — WEEKLY update ✅ (ဒါက ငွေအများဆုံး ချွေတာပေးတယ်)
☐ Ad copy: 3 RSAs per ad group minimum
☐ Extensions: sitelink, callout, structured snippet, call, location
☐ Landing page match — ad promise = page delivers
☐ Quality Score > 7 target
☐ Conversion tracking verified (ဒါ မမှန်ရင် အားလုံး အလကား)
```

# ✅ THE QUALITY GATE SYSTEM

Client ဆီ ဘာမှ မရောက်ခင် **gate ၃ ခု** ဖြတ်ရမယ် —

```
GATE 1 — SELF CHECK (ထုတ်တဲ့သူ)
  "ငါ ဒါကို ငါ့နာမည်နဲ့ portfolio မှာ တင်ရဲလား?"

GATE 2 — PEER / LEAD CHECK (Manager)
  "ဒါက brief ကို ဖြေလား? Spec မှန်လား? Error ရှိလား?"

GATE 3 — CD / CEO CHECK (Standard)
  "ဒါက sharp လား? Distinctive လား? ZYNTH နာမည်နဲ့ ထိုက်တန်လား?"
```

> **Gate မဖြတ်ဘဲ ထွက်သွားတဲ့ work တစ်ခုက — SGD 50,000 တန် client တစ်ယောက် ဆုံးရှုံးစေနိုင်တယ်။**
> Gate ဖြတ်ဖို့ ကြာတဲ့ ၂၀ မိနစ်က အဲဒါနဲ့ ယှဉ်ရင် ဘာမှမဟုတ်ဘူး။
