# 09 — ZYNTH REALITY CHECK (read WITH the playbook, not instead)

The playbook (files 00–08) is the ideal blueprint. This file corrects it
for **where ZYNTH actually is today** so you don't feel lost following a
plan written for a bigger, later version of the agency.

---

## 1. Team — the playbook assumes 6 people. You have 1 + an AI system.
The "Lean Start — 6 people" org is your **Year-1 hiring target, not today.**
Right now the AI bot fills several roles so you can operate solo:

| Playbook role | Filled today by |
|---|---|
| COO / PM / Traffic | You + `/audit`, `/scorecard`, Mon/Fri rhythm nudges |
| Performance / Analytics | `/research`, market FX, scorecard |
| BD | `/bd` (NOVA prospecting) — you approve/send |
| Creative / Copy | `/creative`, `/proposal`, `/event` |
| Back office / proposals | `/proposal` (48h → 3 min), email delivery |

**First real human hire, when cash allows:** an **Ops/Producer** person —
someone to run event delivery on-site (stage 5 DELIVER), which the AI can't.
Not a designer, not a marketer. Delivery hands.

## 2. Market — the playbook prices in SGD. You are dual-market.
Every proposal now uses **live market FX** (`/fx`), not the CBM rate. MMK
figures use the sell rate. Myanmar SME pricing is lower than the SGD tiers
in file 01 — treat those tiers as the **Singapore** ceiling; for Yangon,
anchor to the vendor benchmarks in `backend/knowledge/06_vendors_myanmar.md`
and protect the same 35% margin.

## 3. The playbook's rhythm is now IN the bot.
You don't have to remember file 04's operating cadence — the bot runs it:
- Week 0 audit → `/audit`
- 12-metric scorecard (file 03) → `/scorecard`
- Monday cadence + Friday review (file 04) → automatic Telegram nudges
- Daily brief → 07:00 SGT
- Proposal turnaround moat (file 07: 48h) → `/proposal` in 3 minutes

## 4. What the bot CANNOT do — this stays your job.
- **DELIVER (stage 5):** be in the room, strike the stage, manage vendors day-of.
- **QUALIFY:** decide if a lead is real and worth it.
- **PROVE + EXPAND (stages 6–7):** send the Friday client updates, ask for the
  referral, run the post-event review. This is where agencies die — the bot
  nudges you, but only you can do it.
- **Verify data:** call the venue, confirm the rate. AI can't phone a hotel.

## 5. The honest sequence (don't skip like last time)
1. `/audit` — 2 hours, your starting line. **Do this first.**
2. Phase 1 (file 08, days 1–30): deposit policy, SOW template, cash forecast,
   chase overdue invoices. Boring. The actual path.
3. Get 1–2 real briefs → run through `/proposal` and `/event` → send.
4. Only then think about growth and hiring.

> The tools are leverage. Leverage on zero clients is zero. The build is done;
> the business is the work now.
