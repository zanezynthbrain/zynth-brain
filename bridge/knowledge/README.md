# ZYNTH Knowledge Base

ဒီ folder ထဲက `.md` file တွေကို **agent အားလုံးက အလိုအလျောက်ဖတ်တယ်** —
proposal ထုတ်တဲ့အခါ၊ daily brief လုပ်တဲ့အခါ၊ BD prospect ရှာတဲ့အခါ
ဒီထဲက တကယ့် business အချက်အလက်တွေကို အခြေခံပြီး လုပ်တယ်။

## ဘယ်လိုသုံးမလဲ

1. Obsidian ထဲက note တွေကို ဒီ folder ထဲကူးထည့်ပါ (ရိုးရိုး Markdown ပဲ)
2. Template file တွေထဲက `<!-- TEMPLATE -->` စာကြောင်းကို **ဖျက်ပြီး** တကယ့်အချက်အလက်ဖြည့်ပါ
   - အဲ့ဒီစာကြောင်း ကျန်နေသေးရင် အဲ့ဒီ file ကို agent တွေက **မဖတ်ဘူး** (placeholder စာသားတွေ prompt ထဲမရောက်အောင်)
3. GitHub ကို push လုပ်ပြီး Railway redeploy ဖြစ်တာနဲ့ bot က knowledge အသစ်ကို သုံးပြီ
4. Telegram မှာ `/kb` ရိုက်ရင် ဘယ် file တွေ active ဖြစ်နေလဲ ကြည့်လို့ရတယ်

## Rules

- `README.md` (ဒီ file) ကို agent တွေက ဘယ်တော့မှ မဖတ်ဘူး
- File တစ်ခုကို စာလုံး ~4,000 ထိပဲ ဖတ်တယ် — အရှည်ကြီးတွေထက် အချက်အလက် ကျစ်ကျစ်လျစ်လျစ်ရေးတာ ပိုကောင်းတယ်
- လျှို့ဝှက် password / API key တွေ **လုံးဝမထည့်ပါနဲ့** — ဒီ repo ကို ဖတ်နိုင်တဲ့သူတိုင်း မြင်ရမယ်
