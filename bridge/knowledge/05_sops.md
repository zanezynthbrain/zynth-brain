# Department SOPs (condensed from the ZYNTH ops vault)

## BD — "NOVA" (client acquisition)
Intake prospect → intel report (company snapshot, digital presence audit, gap
analysis, budget signals; every data point flagged CONFIRMED vs ESTIMATED) →
score 0–100 → if ≥ 60: outreach angle + pitch skeleton → price with 35% margin
floor (R1) + 50% deposit clause (R2) → human approves before ANY outreach →
approved prospects logged to pipeline for Monday review.

## Marketing (digital, SEO, SMM)
Intake brief (goal, channels, target CAC/ROAS, budget) → compute baseline KPIs
(CPC, CTR, CAC, ROAS) → budget allocation ranked by projected ROAS → track
organic keyword movement → ad spend ≥ $1,000 gates for approval.
KPIs: roas = revenue/ad_spend · cac = spend/new_customers · ctr% = clicks/impressions×100.

## Creative (video & content)
Intake brief → 3 concept directions (hook, narrative arc, CTA) → full script
(scenes, VO, on-screen text) → production checklist (pre/prod/post) →
feasibility score 0–100 (budget/timeline/resource fit; ≥ 70 to auto-proceed) →
publication always gates for approval.

## Events
Intake (type, guests, date, venue constraints) → run-of-show with milestones →
budget across venue/catering/AV/decor/staffing/contingency → vendor scoring
0–100 (cost, reliability, fit) → budget ≥ $5,000 gates for approval.
KPI: budget_variance% = (actual−planned)/planned×100.

## Tech
Intake brief → architecture scaffold + plan → real uptime/health checks (never
fabricated numbers) → maintenance scan (stale deps, broken links, security) →
production deploys and client-facing pushes always gate.

## Ops (financial reporting)
Collect task audit entries → exact ROI per task = (net_gain−cost)/cost×100
(computed deterministically, never model arithmetic) → aggregate KPIs → flag
ROI below −10% → executive summary; daily 18:00, weekly Friday 19:00.
