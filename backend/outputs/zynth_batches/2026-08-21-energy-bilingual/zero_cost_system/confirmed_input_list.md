# ZYNTH Zero-Cost-First System — Confirmed Inputs

## User Constraints

| Item | Confirmed constraint |
|---|---|
| API spend | Do not rely on paid APIs at the current stage. |
| Existing work | Continue producing proposal batches in the current structured campaign-proposal style. |
| Tool recommendation | Research beyond the AI products already mentioned and recommend only tools with practical fit. |
| Collaboration | Support a future multi-AI review workflow, but do not require API access to begin. |
| Tracking | Use one living master tracker rather than a new disconnected file on every run. |
| Dashboard | Keep the portfolio current and auditable; initial solution must work without paid API automation. |
| Build priority | Build a usable zero-cost-first tracker and templates before any optional paid integration. |

## Available Inputs

| Input | Intended use |
|---|---|
| Existing Energy batch concept data, bilingual proposals, video treatments, visual packages and monitoring workbook | Populate a real example portfolio and demonstrate canonical records. |
| Existing campaign production operating model | Template for campaign/activation lifecycle and G0–G7 approvals. |
| Existing commercial/storyboard definition of done | Template for standalone commercial record and storyboard requirements. |
| Existing master-tracker data dictionary | Column rules, IDs, statuses and update logic. |
| GitHub repository and Google Drive destination | Optional linked artifact references; no new external paid service required. |

## Build Deliverables for This Phase

1. A Burmese-first **ZYNTH Master Tracker** spreadsheet with campaign, commercial, research, AI council, budget, task/approval, asset and learning tabs.
2. A live-in-file dashboard and data-validation controls that operate without any third-party API.
3. A proposal-run update guide that explains how to update existing records rather than create a fresh workbook each time.
4. A research-backed tool comparison with a strict no-cost-first recommendation and optional upgrade paths clearly separated.
5. A reusable, provider-neutral AI Council template that can accept manual copy/paste contributions from any AI tool with no API key.

## Explicit Non-Goals for the Initial Build

- No paid API key, token, connector or external model will be required.
- No real-time paid-data feed, automatic client outreach, external publishing, paid-media spend or CRM write-back will be enabled.
- No unapproved third-party account will be connected.
