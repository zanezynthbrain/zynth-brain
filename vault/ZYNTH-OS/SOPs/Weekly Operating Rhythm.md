# Weekly Operating Rhythm

**Steps.**
1. Mon 08:30 — MD learning brief (one discipline)
2. Mon 08:45 — weekly cadence + priorities (reply with your 3)
3. Daily 06:30 — market research adds prospects
4. Daily 08:00 — CEO cycle → department briefs
5. Daily 18:00 — end-of-day report
6. Daily 21:00 — nightly consolidation (gaps + actions)
7. Fri 15:30 — client updates + weekly review (non-negotiable)

**Standard.** The rhythm carries the company so nothing depends on memory. The speed moat: reply < 4h, proposals < 48h, Friday updates always.
