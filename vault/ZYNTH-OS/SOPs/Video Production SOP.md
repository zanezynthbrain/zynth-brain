# Video Production SOP

**Steps.**
1. `/video <brief>` (or `/video tiktok <brief>`) → production package
2. Review concept + bilingual script + storyboard
3. Render storyboard frames (chat, OpenArt) if needed
4. Lock budget (MMK, RFQ vendors)
5. Shoot (outsourced crew, ZYNTH directs) → post (Resolve/Premiere/CapCut)
6. Deliver masters + platform cutdowns + subtitles

**Standard.** The edit is decided before the shoot. −14 LUFS online. Licensed music for client work.
