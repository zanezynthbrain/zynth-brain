# BD Prospecting SOP

**Steps.**
1. `/scout <sector>` daily (rotates sectors) → new fit-scored prospects
2. Review `/prospects`; push hot ones forward
3. `/export` to CSV or `/sync` to Google Sheet for the full list
4. Qualify → `/lead add` (moves into the working pipeline)
5. Draft outreach (Head of BD) → MD sends
6. Update stage: contacted → meeting → proposal → won/lost

**Standard.** Quality over volume: real companies, deduped, fit-scored, contacts verified before outreach. The Sheet is the browse layer; JSON is source of truth.
