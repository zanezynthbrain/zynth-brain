# Proposal SOP

**Steps.**
1. Capture the brief (client, goal, scale, budget, deadline, market)
2. `/proposal <brief>` → full IGNITE-standard Word doc
3. CEO/CFO QC: pricing protects 35% margin, market FX, one-line ask present, no empty sections
4. MD approves
5. Send from MD's inbox (50% deposit clause)
6. Log to the pipeline + proposal library

**Standard.** 48-hour turnaround. Every proposal: real tables, measurement/attribution, verified-vs-indicative vendors, 50% deposit.
