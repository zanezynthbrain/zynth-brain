# Creative Project SOP

**Steps.**
1. Brief in (objective, audience, deliverables, deadline)
2. Creative Director sets the concept (distinctive, not generic)
3. Produce: copy / design / video per the brief
4. Internal QC before the client sees it
5. MD approves → deliver
6. File the piece in the portfolio (even with no client — build proof)

**Standard.** No empty shells. Every deliverable is complete, on-brand, and portfolio-worthy. With no clients yet, run self-initiated projects to build the book.
