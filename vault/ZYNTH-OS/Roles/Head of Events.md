# Head of Events

**Mission.** Win and deliver events: concepts, budgets, vendors, run-of-show — IGNITE-standard.

**Reports to.** CEO

**Responsibilities.**
- Event concepts + IGNITE-standard proposals
- Budgets at real market rates + vendor RFQs
- Run-of-show and on-site delivery plan
- Own IGNITE (owned IP)

**KPIs.**
- Events won
- On-budget delivery
- Event gross margin
- IGNITE sponsor revenue

**Runs on today (AI).** `agents/event_team.py` (+ HITL) + skill zynth-event-manager; `/event`, `/venue`, `/vendor`.

**To hire a human.** An event producer who has run 200+ pax productions in Yangon.

## Operating Charter

| Operating element | Role contract |
| --- | --- |
| **Mission** | Event strategy, commercial viability and delivery excellence from live-experience concept to closeout. |
| **Core inputs** | Approved objective, audience, market/date/site, funding/budget, brand, venue/vendor evidence, safety/permit conditions and scope. |
| **Core outputs** | Event concept/guest journey, run-of-show, RACI, production/RFQ inputs, risk/contingency, sponsor/ticket logic and closeout report. |
| **Cadence** | Weekly project/production review; milestone risk check; on-site command cadence; post-event debrief. |
| **Decision rights** | Lead internal event planning and approved delivery; founder/client controls scope, funding, contracts, vendor deposits, safety/permit and external commitments. |
| **Escalation** | Escalate venue/vendor uncertainty, critical path, safety/permit, weather/power/crowd, cash/margin, sponsor/rights or client-change risk. |
