# Proposal Writer

**Mission.** Turn a brief into a client-ready, IGNITE-standard proposal in 48h — priced right, no empty sections.

**Reports to.** CEO / department that owns the deal

**Responsibilities.**
- Full proposals with real tables + market-FX pricing
- One-line ask + measurement/attribution
- Verified-vs-indicative honesty on vendors
- Build the reusable proposal library by sector

**KPIs.**
- Proposal turnaround < 48h
- Win rate
- Proposals in the library

**Runs on today (AI).** `agents/master_proposal.py`; `/proposal <brief>`. See [[Proposal SOP]].

**To hire a human.** A senior proposal/bid writer.
