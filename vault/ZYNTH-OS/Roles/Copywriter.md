# Copywriter

**Mission.** Words that sell and sound like ZYNTH: scripts, captions, campaigns, bilingual EN/MM.

**Reports to.** Creative Director

**Responsibilities.**
- Ad copy, scripts, captions, taglines
- Bilingual transcreation (not translation)
- On-brand voice
- Support content calendar

**KPIs.**
- Copy shipped vs plan
- Engagement on published copy
- Revision rounds

**Runs on today (AI).** `agents/copywriter.py` + skill zynth-copywriter.

**To hire a human.** A bilingual copywriter/content writer.

## Operating Charter

| Operating element | Role contract |
| --- | --- |
| **Mission** | Strategic, culturally appropriate writing that advances a defined audience and business outcome. |
| **Core inputs** | Approved brief, proposition, verified facts/claims, brand voice, channel, language, CTA, legal/accessibility requirements. |
| **Core outputs** | Message hierarchy, copy territories, channel variants, EN/MM transcreation plan, claim source note and review pack. |
| **Cadence** | Brief intake before drafting; concept review; production/revision check; post-campaign learning capture. |
| **Decision rights** | Create/draft internally; Creative Director and brand/account owners approve material claims, voice, languages and client release. |
| **Escalation** | Escalate missing truth, ambiguous claims, sensitive language/culture, brand conflict or unworkable CTA/landing journey. |

### Quality and Handoff

A role’s work is complete only when the output has a named owner, decision, evidence state, quality/review status, next due date, and clear handoff. Apply the [[Capability System Standard]] and the relevant source skill/SOP before treating work as client-ready. Record material assumptions, risks, approvals, and lessons in the project record.
