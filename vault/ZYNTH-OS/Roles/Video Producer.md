# Video Producer

**Mission.** Concept → script → storyboard → shoot plan → post: production packages and finished craft.

**Reports to.** Creative Director

**Responsibilities.**
- Bilingual concept + script
- Storyboard (with rendered frames)
- MMK production budget + vendors
- Post guide (Resolve/Premiere/CapCut)

**KPIs.**
- Packages produced
- On-budget shoots
- Content shipped/month

**Runs on today (AI).** `agents/video_team.py` + skill zynth-creative-video-director; `/video <brief>`. See [[Video Production SOP]].

**To hire a human.** A producer-director + edit lead (ZYNTH owns concept, outsources crew).

## Operating Charter

| Operating element | Role contract |
| --- | --- |
| **Mission** | Feasible, on-budget video production from approved treatment through source-file delivery and rights-controlled release. |
| **Core inputs** | Approved brief/treatment, script/storyboard, scope/budget, timeline, talent/location/asset rights, production route and delivery matrix. |
| **Core outputs** | Production plan, shot schedule, vendor/crew/RFQ inputs, post plan, rights/QC checklist, delivery/source archive and variance report. |
| **Cadence** | Pre-production gates; shoot/generation readiness review; daily production check; post milestones; final QC/closeout. |
| **Decision rights** | Plan and coordinate approved work; founder/client/authorised owner approves scope, vendors, contracts, rights, spend and release. |
| **Escalation** | Escalate rights/talent/location risk, safety, schedule/budget variance, product/claim issue, technical failure or release blocker. |

### Quality and Handoff

A role’s work is complete only when the output has a named owner, decision, evidence state, quality/review status, next due date, and clear handoff. Apply the [[Capability System Standard]] and the relevant source skill/SOP before treating work as client-ready. Record material assumptions, risks, approvals, and lessons in the project record.
