## 1. Event Brief Intake (always start here)

Confirm before planning anything:

- [ ] Event objective — what must be true the day after? (leads, awareness, sales, community, internal morale)
- [ ] Audience — who, how many, how invited
- [ ] Date(s) and flexibility
- [ ] Budget — total, and whether it includes ZYNTH's fee
- [ ] Format — physical / hybrid / virtual; seated / standing / flow-through
- [ ] Market — SG or MM (changes vendors, permits, payment norms, language)
- [ ] Client's non-negotiables (VIPs, sponsors, brand rules)
- [ ] Success metrics — registrations, attendance rate, leads captured, content produced, media coverage

If budget is unknown, give three scenario budgets (lean / standard / premium) rather than asking again.

## 2. Master Event Workplan (build backwards from event day)

| Phase | When | Key Outputs |
|---|---|---|
| **Concept & Proposal** | T-12 to T-10 weeks | Theme, format, budget, proposal deck |
| **Lock-in** | T-10 to T-8 | Venue confirmed, date locked, deposit paid, key vendors contracted |
| **Build** | T-8 to T-4 | Creative assets, invitations out, registration live, programme drafted |
| **Drive** | T-4 to T-1 | Marketing push, confirmations, run of show v1, vendor briefings |
| **Final Week** | T-7 to T-1 days | Final headcount, run of show locked, manpower briefing, contingency review |
| **Event Day** | T-0 | Execute against run of show |
| **Post-Event** | T+1 to T+7 | Thank-you comms, content rollout, post-event report, invoice balance |

Compress proportionally for shorter lead times — but flag risk to the client if under 4 weeks for a physical event.

## 3. Event Budget Template

Build every budget in these categories (SGD or USD):

1. **Venue** — rental, setup/teardown hours, insurance, permits
2. **F&B** — per-pax catering, beverages, service staff
3. **AV & Technical** — sound, lighting, LED/projection, livestream
4. **Production & Fabrication** — stage, backdrop, booths, signage, print
5. **Programme** — emcee, speakers, performers, entertainment
6. **Marketing & Content** — design, paid ads, photographer, videographer
7. **Logistics & Manpower** — transport, ushers, security, registration crew
8. **Guest Experience** — door gifts, lanyards, F&B vouchers, swag
9. **Contingency** — always 10% of subtotal
10. **ZYNTH Management Fee** — per tier table above

Present as a table with line items, unit costs, and a clear total. Mark estimates vs confirmed quotes. For vendor sourcing, use the **zynth-vendor-finder** skill.

**SG benchmarks (2026):** hotel ballroom S$8K–25K/day; corporate catering S$35–80/pax; AV package S$3K–12K; emcee S$800–2,500; event photographer S$600–1,200/day.
**MM benchmarks:** hotel ballroom USD 1K–4K/day; catering USD 8–25/pax; AV USD 500–2,500; emcee USD 150–500. Verify current prices — MM costs shift with exchange rates.

## 4. Run of Show (ROS) Format

The ROS is the single source of truth on event day. Format:

| Time | Duration | Segment | On Stage | AV/Tech Cue | Owner | Notes |
|---|---|---|---|---|---|---|

Rules:
- 5-minute resolution minimum; 1-minute for live broadcast moments
- Every segment has ONE named owner
- Include pre-doors timeline (crew call, setup checks, rehearsal, doors open)
- Include a "what breaks first" column for high-risk segments (livestream, demos, VIP arrivals)
- Build buffer: programmes always run 10–15% over

## 6. Risk & Contingency Checklist

For every event, document Plan B for: weather (outdoor), AV failure, no-show emcee/speaker, low turnout (<60% of confirmed), overcrowding, power loss, medical incident, key vendor failure. SG-specific: licensing (SFA for F&B sampling, public entertainment licence, URA/town council for public spaces). MM-specific: permits via venue, cash payment logistics, generator backup as default.

---

## 7. Post-Event Report (client deliverable)

Always produce within 7 days — this is the upsell document:

1. Executive summary — objective vs result
2. Attendance funnel — invited → registered → attended
3. Content performance — reach, engagement, media coverage
4. Budget reconciliation — planned vs actual
5. Photo/video highlights
6. Recommendations — what to do next (the upsell: next event, retainer, always-on social)
