# TD.1. Exhibition Booth Standards

## 1. Standard Dimensions & Regulations

### 1.1. North American Standards (Imperial)
- **Inline Booth (10' x 10')**: 100 sq ft. Backwall height max 8' (2.44m). Side walls max 4' (1.22m) for the front half to maintain sightlines.
- **Perimeter Booth**: Same as inline but located on the outer walls. Height can sometimes extend to 12'.
- **Island Booth (20' x 20' or larger)**: Open on all four sides. Height typically allowed up to 16'-20' depending on venue.

### 1.2. International Standards (Metric)
- **Standard Unit (3m x 3m)**: 9 sqm. Height typically 2.5m.
- **Large Scale**: Multiples of 3m (e.g., 6m x 6m, 9m x 12m).

## 2. Booth Types & Configurations

| Type | Description | Key Advantage |
| :--- | :--- | :--- |
| **Inline (Linear)** | One side open to the aisle. | Cost-effective, standard. |
| **Corner** | Two sides open to aisles. | Better visibility, two entry points. |
| **Peninsula** | Three sides open to aisles. | High impact, "end-cap" position. |
| **Island** | Four sides open to aisles. | Maximum visibility, central feature. |

## 3. Structural Components
- **Truss Systems**: Global Truss (F34) standard for hanging lights and banners.
- **Wall Systems**: Octanorm (aluminum frames), Maxima (large scale), or custom wood/MDF.
- **Flooring**: Raised platform (typically 40mm-100mm) for cable management, or carpet/vinyl.

## 4. SOP: Standard Booth Layout Workflow
1.  **Define Boundary**: Create the floor plane based on the brief (e.g., 6x6m).
2.  **Set Height Limits**: Establish the 3D "envelope" based on regulations.
3.  **Place Core Structure**: Backwalls, storage room (essential for logistics), and main branding tower.
4.  **Zoning**:
    *   **Public Zone**: Front counter, interactive screens.
    *   **Semi-Private Zone**: Lounge area, product demo stations.
    *   **Private Zone**: Meeting room, storage.
5.  **Lighting Rig**: Place a truss at 4m-5m height with wash and spot lights.
