## 2. Meta Ads (Facebook & Instagram)

### Campaign Structure (always use this hierarchy):
```
CAMPAIGN (Objective)
└── AD SET (Audience + Budget + Placement)
    └── AD (Creative + Copy)
```

### Objective Selection Guide:
| Business Goal | Meta Objective |
|---|---|
| Brand awareness / reach | Awareness |
| Website traffic | Traffic |
| Video views | Video Views |
| Lead generation | Leads |
| App installs | App Promotion |
| Purchases / Conversions | Sales |
| Enquiries via Messenger | Engagement → Messenger |

### Audience Setup:

**Cold Audiences (top of funnel):**
- Interest targeting: Stack 2–3 relevant interests max — over-stacking restricts delivery
- Demographic layering: Age, gender, location only when strategically necessary
- Broad targeting: For Singapore market with good creative, broad + creative-led often outperforms interest stacks
- Myanmar: Facebook's interest data is thinner — use broader targeting with strong creative

**Warm Audiences (mid/bottom funnel):**
- Website visitors (last 30 / 60 / 90 days) — requires Pixel
- Video viewers (25%, 50%, 75%, 95% thresholds)
- Instagram / Facebook page engagers (30 / 60 / 90 days)
- Lead form openers / submitters

**Lookalike Audiences:**
- Build from: Customer list, purchasers, or high-value leads
- Start with 1–3% lookalike for quality; 3–7% for scale
- Always exclude source audience from lookalike ad set

### Ad Formats & When to Use:
| Format | Best For |
|---|---|
| Single image | Simple message, product showcase, offer |
| Carousel | Multiple products, step-by-step story, feature list |
| Video (6–15s) | Awareness, thumb-stop, product demo |
| Video (30–60s) | Storytelling, brand, consideration |
| Collection | E-commerce product browsing |
| Lead form | In-app lead capture, no landing page needed |
| Instant Experience | Immersive mobile brand experience |

### Meta Benchmarks (Singapore market):
| Metric | Awareness | Lead Gen | Conversion |
|---|---|---|---|
| CPM | $8–$18 | $10–$20 | $12–$25 |
| CTR | 0.8–1.5% | 1.0–2.5% | 1.5–3.5% |
| CPC | $0.80–$2.00 | $0.60–$1.50 | $0.50–$1.20 |
| CPL | — | $8–$30 | — |

### Myanmar Meta Notes:
- CPMs significantly lower than Singapore: $1–$5 typical
- Facebook Feed > Instagram for reach in Myanmar
- Messenger ads and click-to-Messenger highly effective
- Burmese script in ad copy strongly recommended for broad audiences
- Mobile-optimised creatives mandatory — vertical video (9:16) preferred

## 3. TikTok Ads

### Campaign Structure:
```
CAMPAIGN (Objective + Budget)
└── AD GROUP (Audience + Placement + Schedule)
    └── AD (Creative)
```

### Objective Selection:
| Goal | TikTok Objective |
|---|---|
| Brand awareness | Reach |
| Video views | Video Views |
| Website traffic | Traffic |
| App installs | App Install |
| Lead generation | Lead Generation |
| Conversions | Conversions |

### Audience Targeting on TikTok:
- **Interest & behaviour:** TikTok's interest categories — broader is often better on TikTok
- **Custom audiences:** Website visitors (Pixel required), customer list upload
- **Lookalike:** Build from converters or customer list
- **Creator marketplace:** For influencer-paid hybrid campaigns

### Creative Requirements for TikTok Ads:
- **Format:** Vertical video 9:16 mandatory
- **Length:** 9–15 seconds for best completion rates; 21–34 sec for storytelling
- **Hook:** First 2–3 seconds must stop the scroll — start mid-action, not with logo
- **Text overlay:** Captions/text on-screen — many users watch without sound
- **Native feel:** Ads that look like organic TikToks outperform polished productions
- **Music:** Use TikTok's licensed library — original trending audio boosts performance

### TikTok Benchmarks (Singapore):
| Metric | Benchmark |
|---|---|
| CPM | $8–$15 |
| Video View Rate (6s) | 15–30% |
| CTR | 0.5–1.5% |
| CPC | $0.50–$2.00 |

## 4. Google Ads

### Search Campaign Setup:

**Campaign structure:**
```
CAMPAIGN (Budget + Location + Language)
└── AD GROUP (Theme / Intent cluster)
    └── KEYWORDS
    └── ADS (RSA — Responsive Search Ads)
```

**Keyword match types:**
| Match Type | When to Use |
|---|---|
| Exact [keyword] | High-intent, controlled spend |
| Phrase "keyword" | Moderate control, more reach |
| Broad keyword | Discovery — use with Smart Bidding only |

**Keyword strategy:**
- Group keywords by intent: navigational / informational / commercial / transactional
- Build separate ad groups per intent cluster — never mix intent in one ad group
- Add negative keywords from day 1 — protect budget from irrelevant searches

**Responsive Search Ads (RSA) structure:**
- 15 headlines (30 char max each) — write them independently, Google mixes them
- 4 ad descriptions (90 char max each)
- Include keyword in at least 2 headlines
- Include CTA in at least 1 headline and 1 description
- Include a proof point (award, stat, years in business) in 1 description

**Bidding strategy guide:**
| Campaign Stage | Bidding Strategy |
|---|---|
| New campaign, no data | Maximise Clicks (then switch after 30–50 conversions) |
| Lead gen with conversion tracking | Target CPA |
| E-commerce with revenue data | Target ROAS |
| Brand awareness | Target Impression Share |

### Google Display — Retargeting Setup:
- **Segment 1:** All website visitors (last 30 days) — exclude converters
- **Segment 2:** Product/service page visitors (last 14 days) — higher intent
- **Segment 3:** Cart abandoners (e-commerce) — last 7 days
- Frequency cap: 3–5 impressions per user per day to avoid ad fatigue

## 5. A/B Testing Framework

Always test one variable at a time. Document every test.

**Test priority order:**
1. Creative (biggest impact — test this first)
2. Audience
3. Offer / CTA
4. Headline / copy
5. Placement

**Test structure:**
| Variable | Control | Variant | Winner Criteria | Minimum Run Time |
|---|---|---|---|---|
| Creative format | Static image | Video | CTR / CPL | 7 days / 1,000 impressions |
| Audience | Interest | Lookalike | CPL / ROAS | 7–14 days |
| CTA | "Learn More" | "Get a Free Quote" | CTR / CVR | 7 days |

**Rule:** Never end a test before statistical significance or minimum impression threshold.

## 6. Optimisation Checklist (Weekly)

Run through this every week on active campaigns:

**Budget & Pacing:**
- [ ] Is budget pacing correctly (not front-loading or under-spending)?
- [ ] Are any ad sets in "learning" phase still after 7+ days? (Consolidate or reset)

**Creative Performance:**
- [ ] Which ad has the lowest CPM / highest CTR? Increase budget to it.
- [ ] Which ads have CTR below 0.5%? Pause and replace.
- [ ] Have any creatives been running 3+ weeks? Refresh to avoid fatigue.

**Audience:**
- [ ] Is frequency above 3.0 on awareness campaigns? Expand audience or rotate creative.
- [ ] Has retargeting audience size dropped below 500? Widen the window.

**Conversion:**
- [ ] Is the Pixel / conversion tracking firing correctly?
- [ ] Is landing page load time under 3 seconds on mobile?
