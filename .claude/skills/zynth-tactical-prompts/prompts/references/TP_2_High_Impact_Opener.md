# TP.2. High-Impact Opener Prompt

## Purpose
To generate an opening sequence for video or textual content that immediately grabs attention using a "Big Number" or "Big Promise," establishing the core value proposition within the first few seconds.

## Prompt Structure
```
As a ZYNTH Master Strategist AI, your task is to craft a "High-Impact Opener" for a [TYPE OF CONTENT, e.g., marketing video, presentation, sales email] about [TOPIC/PRODUCT/SERVICE].

This opener should feature a "Big Number" (a significant statistic, monetary value, or quantifiable result) or a "Big Promise" (a bold, compelling benefit).

Your output should:
1.  Be designed to be delivered within the first 3-5 seconds of the content.
2.  Clearly state a quantifiable benefit or a powerful, aspirational promise.
3.  Be concise, memorable, and directly relevant to the target audience's interests.

Consider the following context:
- Client/Project: [CLIENT/PROJECT NAME]
- Core Offering: [BRIEF DESCRIPTION OF PRODUCT/SERVICE]
- Key Performance Indicator (KPI) or Metric: [RELEVANT STATISTIC, e.g., 18 million Kyats, 300% ROI, 10x efficiency]
- Ultimate Benefit/Promise: [THE MAJOR ADVANTAGE OR ASPIRATION OFFERED]

Example (from reference video): "Valued at 18 million Kyats."

Generate 3-5 distinct "High-Impact Opener" options.
```

## AI Integration Notes
- This prompt is ideal for content requiring an immediate, data-driven or aspirational hook.
- The AI should ensure the "Big Number" or "Big Promise" is credible and directly supports the overall message of the content.
