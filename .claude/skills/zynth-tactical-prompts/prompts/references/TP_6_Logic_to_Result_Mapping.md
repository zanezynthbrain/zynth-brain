# TP.6. Logic-to-Result Mapping Prompt

## Purpose
To generate instructions for an AI video editor or content creator to visually connect complex technical logic (e.g., code, workflow diagrams) with its tangible real-world results or user experience, making abstract concepts relatable and demonstrating impact.

## Prompt Structure
```
As a ZYNTH Master Strategist AI, your task is to provide "Logic-to-Result Mapping" instructions for a [TYPE OF CONTENT, e.g., explainer video, product demo, tutorial] about [TECHNICAL CONCEPT/SYSTEM].

Your instructions should guide an AI visual tool to:
1.  Always pair a visual representation of the "logic" (e.g., a workflow diagram, code snippet, data flow chart) with a corresponding visual representation of its "result" or "user experience" (e.g., a chat interface, a dashboard, an animation, a physical product interaction).
2.  Ensure smooth and clear transitions between the logic and the result, emphasizing the cause-and-effect relationship.
3.  Specify the duration and visual emphasis for both the logic and result segments.

Consider the following context:
- Technical Logic to Explain: [DESCRIPTION OF THE LOGIC, e.g., "how the AI processes a customer query"]
- Visual for Logic: [DESCRIPTION OF UI/CODE/DIAGRAM, e.g., "n8n workflow showing query parsing nodes"]
- Corresponding Result/UX: [DESCRIPTION OF THE OUTCOME, e.g., "mobile chat interface with AI response"]
- Overall Goal: [WHAT THE VIEWER SHOULD UNDERSTAND ABOUT THE CONNECTION]

Generate 3-5 distinct "Logic-to-Result Mapping" sequences, detailing the visual pairing and transition.
```

## AI Integration Notes
- This prompt is critical for demystifying complex technical systems and highlighting their practical value.
- The AI should be able to identify logical breakpoints in the explanation to insert result visuals effectively.
- The output should be actionable by AI video editing and presentation tools.
