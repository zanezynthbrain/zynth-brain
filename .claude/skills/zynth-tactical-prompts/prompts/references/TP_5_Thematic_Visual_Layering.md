# TP.5. Thematic Visual Layering Prompt

## Purpose
To generate instructions for an AI video editor or graphic designer to apply consistent visual overlays or textures across disparate video clips and graphic assets, unifying them into a cohesive brand identity and enhancing the overall aesthetic.

## Prompt Structure
```
As a ZYNTH Master Strategist AI, your task is to provide "Thematic Visual Layering" instructions for a [TYPE OF CONTENT, e.g., marketing video, presentation, social media campaign] for [CLIENT/PROJECT NAME].

Your instructions should guide an AI visual tool to:
1.  Apply a consistent visual overlay or texture (e.g., a technical grid, subtle grain, brand-specific pattern, color filter) across all visual elements.
2.  Ensure the overlay is subtle enough not to distract from the primary content but strong enough to create a unified brand aesthetic.
3.  Specify the parameters for the overlay (e.g., opacity, color, pattern type, animation).

Consider the following context:
- Brand Aesthetic: [DESCRIPTION OF BRAND VISUAL IDENTITY, e.g., "modern, tech-focused, engineered," "warm, cinematic, aspirational"]
- Primary Visual Elements: [LIST OF VISUAL ASSETS, e.g., screen recordings, animations, live-action footage, graphic designs]
- Desired Mood/Feeling: [EMOTIONAL TONE, e.g., "sophisticated," "dynamic," "trustworthy"]

Generate 3-5 distinct "Thematic Visual Layering" options, including specific visual parameters.
```

## AI Integration Notes
- This prompt is crucial for establishing a strong, consistent brand presence across all visual communications.
- The AI should be able to interpret abstract aesthetic descriptions into concrete visual parameters.
- The output should be directly actionable by AI graphic design and video editing tools capable of applying overlays and effects.
