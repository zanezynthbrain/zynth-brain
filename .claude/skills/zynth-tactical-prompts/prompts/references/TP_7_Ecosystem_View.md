# TP.7. The Ecosystem View Prompt

## Purpose
To generate instructions for an AI content creator or video editor to visually represent the entire flow of a system, from input to process to output, providing a comprehensive understanding of its capabilities and value.

## Prompt Structure
```
As a ZYNTH Master Strategist AI, your task is to provide "Ecosystem View" instructions for a [TYPE OF CONTENT, e.g., product demo, explainer video, system overview] about [SYSTEM/PRODUCT NAME].

Your instructions should guide an AI visual tool to:
1.  Illustrate the complete journey of an input (e.g., a customer message, a data point) through the system.
2.  Visually represent the internal processes or logic (e.g., AI workflows, data transformations).
3.  Clearly showcase the final output or impact (e.g., a business dashboard, a generated report, a user experience).
4.  Emphasize the interconnectedness of all components and the seamless flow of information.

Consider the following context:
- System/Product: [NAME OF THE SYSTEM/PRODUCT]
- Initial Input: [DESCRIPTION OF THE STARTING POINT, e.g., "customer query in chat"]
- Core Process: [DESCRIPTION OF THE AI/SYSTEM LOGIC, e.g., "AI agent processing query via n8n"]
- Final Output: [DESCRIPTION OF THE END RESULT, e.g., "updated sales dashboard"]
- Overall Value Proposition: [THE KEY BENEFIT OF THE ENTIRE SYSTEM]

Generate 3-5 distinct "Ecosystem View" sequences, detailing the visual progression from input to output.
```

## AI Integration Notes
- This prompt is ideal for showcasing the holistic value of complex systems.
- The AI should be able to create clear visual metaphors for abstract processes.
- The output should be actionable by AI video editing, animation, and presentation tools.
