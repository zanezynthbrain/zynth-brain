# CapCut — Deep Craft Reference (Mobile + Desktop)

CapCut is the fastest path to social-native, trend-aware edits — the ZYNTH
workhorse for Reels/TikTok/Shorts volume. Two apps: **Mobile** (iOS/Android)
and **Desktop** (more like a mini-Premiere). Give exact tap/click-paths.

> Note for client work: CapCut's free assets/fonts/music have **commercial-use
> caveats**. For paid brand work, use licensed music and cleared fonts, and
> avoid the "CapCut" outro/watermark. CapCut Pro (or Commercial) is required to
> remove watermark and unlock some assets. Flag this before delivering a client ad.

---

## 1. Mobile — the core loop
- **New Project** → select clips → editor opens with the **timeline** and a bottom **toolbar** (Edit, Audio, Text, Stickers, Overlay, Effects, Filters, Format, Canvas, Adjustment).
- **Trim/split:** tap a clip → **Split** at playhead, drag ends to trim, hold-drag to reorder.
- **Speed:** select clip → **Speed** → *Normal* (single value) or **Curve** (presets: Montage, Hero, Bullet, Jump-cut, Flash-in/out — or Custom to draw the ramp). Enable "smooth slow-mo" (optical flow) for clean slow sections.
- **Audio:** **Audio → Sounds** (library / trending), **Extracted** (from a video), **Voiceover** (record), **Effects**. Tap **Beat** → auto-detect beats → markers to cut on the beat.
- **Text:** **Text → Add text** → type → **Style** (font, colour, stroke, background, shadow), **Effects**, **Bubble**, **Animation** (In/Out/Loop). **Auto Captions** (Text → Auto captions → language incl. English/Burmese*) transcribes speech to styled subtitles — then edit wrong words. (*MM auto-caption accuracy varies — always proofread.)
- **Overlay:** **Overlay → Add overlay** = picture-in-picture / second layer → position, scale, blend mode, mask, chroma key.
- **Effects:** **Effects → Video effects** (Trending, Bling, Retro, Glitch…) and **Body/Face effects**. Apply to whole clip or trim the effect's own bar.
- **Filters:** one-tap looks; dial intensity. **Adjustment** = manual (brightness, contrast, saturation, HSL, curves, temperature) — use this for real grading, not just filters.
- **Keyframes:** the **diamond ◇** icon — set on Position/Scale/Rotation/Opacity/Volume/filter-intensity → move playhead → change → auto-creates the tween. This is how you do moves, reveals, and audio fades.
- **Format** = aspect ratio (9:16, 1:1, 16:9); **Canvas** = background/blur/colour for letterboxed clips.

## 2. Desktop — when you need more control
- Layout closer to an NLE: media pool, multi-track timeline, Player, right-hand **inspector** (Basic/Animation/Adjustment/Speed/Video effects).
- Multiple video/text/effect tracks, easier keyframing, **Auto Captions**, **Text-to-Speech**, **Auto Reframe** (resize to another aspect with subject tracking), **Remove Background** (AI, no green screen needed), **Retouch/Enhance**.
- Better for 60–120s brand pieces and when you want layered graphics without leaving CapCut.

---

## 3. Signature CapCut techniques (trend-craft)
- **Beat-synced montage:** Audio → Beat auto-markers → split/cut each shot to a beat → add transitions on beats. The backbone of hype reels.
- **Velocity / speed-ramp edits:** Speed → Curve → *Hero* or Custom; pair a fast ramp with a whip/zoom transition and a whoosh SFX.
- **Zoom punch on a word:** keyframe Scale 1.0→1.15 over 3–4 frames on the accented syllable + a subtle shake effect.
- **Auto Captions karaoke style:** Auto captions → choose an animated template so words pop per-syllable (huge for retention; standard on MM social).
- **Chroma key overlay:** Overlay → add green-screen clip → **Cutout → Chroma key** → pick green → refine intensity/shadow.
- **AI cutout (no green screen):** Overlay/clip → **Cutout → Auto** (removes background) → place over new BG.
- **Trending transition:** Effects/Transitions library updates constantly — match the *current* trend, but only if it serves the idea (don't trend-chase a premium brand).
- **Text reveal:** Text → Animation → In (Typewriter / Rise / Fade) synced to VO.

---

## 4. Grading in CapCut (yes, you can)
Use **Adjustment** (not just Filters): set exposure/contrast/highlights/shadows, then **HSL** to control individual colours, **Curves** for contrast and colour, **Temperature/Tint** for WB. Add a light **Filter** on top at low intensity for a look. For consistent multi-clip grade, copy the adjustment clip's settings (long-press → copy → paste to others) or apply an adjustment layer (desktop).

---

## 5. Export
- **Mobile:** top-right **Export** → set **Resolution** (1080p min for brand; 4K if source allows), **Frame rate** (match source; 30 for social, 24 for cinematic, 60 for smooth motion), bitrate (Higher). Toggle "Smart HDR" off unless intended.
- **Desktop:** Export → format MP4 (H.264), 1080p/4K, bitrate high; set filename/location.
- **Watermark:** remove the ending CapCut outro clip; ensure no template watermark remains. Pro required for some.
- Export platform variants: change **Format** aspect and re-export (or Auto Reframe on desktop) for 9:16 / 1:1 / 16:9.

---

## 6. When to use CapCut vs Resolve/Premiere (advise the user)
- **CapCut:** social reels at volume, trend edits, captions-first content, fast turnarounds, mobile/on-the-go, phone-shot footage. Batch a month of reels here.
- **Resolve:** anything needing real colour grading, multicam, VFX/Fusion, or a broadcast/commercial master.
- **Premiere/AE:** long-form, team workflows, heavy motion graphics, Adobe-pipeline clients.

For a ZYNTH client TVC: concept/board here → shoot → **grade & finish in Resolve**. For the campaign's social cutdowns: **CapCut**. Right tool per deliverable.
