# Concept, Story & Storyboard Craft

The reference for inventing commercial-grade ideas and turning them into a
production-ready, shot-by-shot board. Read this for any "story concept", "ad
idea", "script", "treatment", or "storyboard" request.

---

## 1. From brief to idea (the concept engine)

Never start with visuals. Start with the **strategic core**, then let the idea grow from it.

1. **The one sentence** — what must the viewer *feel, remember, or do*? If it isn't one sentence, keep cutting.
2. **The tension** — every strong ad sits on a human tension (fear vs aspiration, old way vs new way, effort vs ease). Name it.
3. **The single-minded proposition (SMP)** — the ONE thing the film says about the brand. One. Not three.
4. **The idea** — the creative device that dramatises the SMP. Test it against:
   - *Distinctive?* Would a competitor's logo fit at the end? If yes, it's generic — kill it.
   - *Ownable?* Does it come from something true about THIS brand?
   - *Producible?* Can it be shot on the real budget (MM/SG SME scale)?
   - *Legible in 1.5s and in muted playback?*

### Idea territories to push against (pick, then break the cliché)
- **Demonstration** — show the product doing the thing, but with a twist (scale, speed, contrast).
- **Problem→solution** — the workhorse; earn it with a *specific*, human problem, not a stock one.
- **Story/emotional arc** — a character changes because of the brand.
- **Analogy/metaphor** — the product *is like* something unexpected.
- **Hyperbole/absurd** — push a truth to a funny extreme.
- **Insight/relatable** — "so true" recognition (huge in Myanmar social).
- **Founder/behind-the-scenes** — authenticity as the creative.

## 2. The treatment (1 page, before any storyboard)

Deliver this so the client buys the *film*, not just a list of shots:

- **Title / logline** — the film in one evocative line.
- **The idea** — 2–3 sentences: what happens and why it works.
- **Tone & world** — how it feels (e.g. "warm, handheld, morning light, real people, not models").
- **Visual language** — palette, lens feel, movement style, pace, grade direction.
- **Sound world** — music genre/tempo, VO presence, key SFX.
- **Structure** — the beats (see below).
- **Why it works** — tie back to the SMP and audience.

---

## 3. Structures that work at :15 / :30 / :60

- **:15 (social/cutdown)** — Hook (1.5s) → Turn → Payoff/CTA. One idea, one turn.
- **:30 (TVC standard)** — Hook → Setup (the tension) → Escalation → Resolution (brand solves) → Logo/CTA (last 2–3s).
- **:60 (hero/emotional)** — Cold open → Build character/world → Rising beats (3) → Emotional peak → Brand landing → Tag.
- **AIDA for performance ads** — Attention → Interest → Desire → Action; front-load the value, CTA twice (mid + end for skippable).

**Hook menu (first 1.5s):** motion into frame · a face mid-emotion · a pattern-interrupt sound · a bold on-screen question · a "wrong" image that demands explanation. Never a logo, never a slow fade-in.

---

## 4. The visual script (two-column)

Before storyboarding, write the **AV script** — it forces the film to work as picture + sound together:

| VISUAL (what we see) | AUDIO (VO / dialogue / SFX / music) |
|---|---|

- Left column: shot content, action, on-screen text.
- Right column: exact VO/dialogue (bilingual EN/MM if needed), SFX, music cue.
- Time-code the beats so total duration is real, not hopeful.

## 5. Shot language (use the right words)

**Shot sizes:** ECU (extreme close) · CU · MCU · MS · MWS · WS · EWS/establishing.
**Angles:** eye-level · high · low · overhead/top-down · dutch (tilt) · OTS (over-the-shoulder) · POV.
**Movement:** static/lock-off · pan · tilt · push-in/pull-out (dolly) · track/truck · crane/jib · handheld · gimbal float · whip-pan · arc · drone.
**Lens feel:** wide (24–35mm, context, energy) · normal (50mm, natural) · tele (85mm+, compression, intimacy/beauty) · macro (product detail).
**Composition:** rule of thirds · centre (symmetry/power) · leading lines · negative space · frame-in-frame · foreground layering.

Match movement to emotion: push-in = realisation/intensity; pull-out = isolation/reveal; handheld = tension/reality; locked + symmetrical = control/premium.

## 6. Storyboarding — the deliverable

### Board format (per frame)
**Frame image · Shot # · Size/Angle/Movement · Action · Dialogue/VO/SFX · Duration · Notes (lens, lighting, VFX)**

Group the shot list by **location** for shooting, but present the storyboard in **edit order** for the client.

### Generating the frames as images (do this, don't just describe)
For each frame, write a consistent-style image prompt:

> `[shot size] of [subject] [action], [location], [lighting], [lens/mood], [colour palette], cinematic commercial still, [aspect ratio]`

Rules for a board that looks like ONE film:
- **Lock a style line** and repeat it every frame: e.g. *"shot on ARRI, shallow depth of field, warm morning light, teal-and-amber grade, photoreal."*
- **Consistency:** restate the same character/product/wardrobe/location descriptors in every prompt. Note continuity (same shirt, same mug).
- **Aspect ratio:** 16:9 for TVC/YouTube; 9:16 for Reels/TikTok/Shorts; 1:1 only if specified.
- Call the connected image-generation tool once per frame. If a design tool (Canva) is connected, assemble the frames into a labelled storyboard grid.
- If no image tool is available, deliver the full **text board** (still production-ready) and offer to render frames once an image tool is enabled.

### Mood board vs storyboard
- **Mood board** — 6–9 reference frames establishing tone/palette/lighting (do this first for look-dev).
- **Storyboard** — the actual shots of THIS film in sequence.
Deliver mood board at concept stage, storyboard at pre-pro stage.

## 7. Bilingual (Myanmar + English) copy on screen

- Keep on-screen text short — 3–5 words a line; muted viewers read fast.
- Myanmar script needs more vertical line-height and a font that renders Unicode properly (Pyidaungsu, Myanmar3, or a licensed display face). Never squeeze MM text into an EN-sized caption box.
- Provide **both** an EN and MM version of taglines/CTAs; don't machine-translate a pun — transcreate it so it lands in Burmese.
- Subtitle timing: max ~2 lines, ~1.5–4s per card, gap between cards.

---

## 8. Quick self-check before you present

- [ ] One idea, stated in a sentence.
- [ ] Hook works in 1.5s and while muted.
- [ ] Every shot earns its place; nothing decorative.
- [ ] Producible on the real budget (no impossible crane if there's no crane).
- [ ] Sound designed, not assumed.
- [ ] Bilingual on-screen text where the audience needs it.
- [ ] Ends on brand + one clear CTA.
