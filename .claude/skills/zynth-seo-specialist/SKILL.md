## 1. Keyword Research Framework

### Step 1 — Seed Keywords
Start with the business: what does the client sell, and how do their customers search for it?
- List 5–10 core topics (not yet keywords — themes)
- For each topic, brainstorm how a customer in Singapore would search for it
- Consider: beginner searches vs. expert searches, problem-first vs. solution-first

### Step 2 — Keyword Classification
Organise keywords by intent:

| Intent Type | Description | Example |
|---|---|---|
| Informational | Learning, researching | "what is brand strategy" |
| Navigational | Finding a specific brand | "ZYNTH agency Singapore" |
| Commercial | Comparing options | "best marketing agency Singapore" |
| Transactional | Ready to act | "hire brand strategist Singapore" |

### Step 3 — Keyword Prioritisation Matrix
Score each keyword on:
- **Search volume:** Monthly searches (SG data)
- **Difficulty:** How competitive is it? (1–10)
- **Business relevance:** How directly does ranking for this drive leads? (1–10)
- **Priority score:** (Relevance × 2) ÷ Difficulty

Focus first on: high relevance, moderate difficulty, transactional or commercial intent.

### Step 4 — Keyword Mapping
Assign each target keyword to one URL only. No two pages should target the same keyword (keyword cannibalism).

| Target Keyword | Assigned Page / URL | Intent | Monthly Volume | Difficulty |
|---|---|---|---|---|
| | | | | |

## 2. On-Page SEO Checklist

For every page being optimised:

### Title Tag:
- Length: 50–60 characters (will truncate in SERPs beyond this)
- Include primary keyword — ideally near the front
- Include brand name at end for branded pages
- Format: Primary Keyword — Secondary Keyword | Brand Name

### Meta Description:
- Length: 140–155 characters
- Include primary keyword naturally
- Include a clear CTA or value proposition
- Not a ranking factor, but directly impacts CTR

### Header Tags:
- H1: One per page. Contains primary keyword. Matches or closely mirrors title tag.
- H2s: Section headers — include secondary keywords naturally
- H3s: Sub-sections — support the H2 above them

### Body Content:
- Primary keyword in first 100 words
- Natural keyword density — write for humans, not bots
- Minimum 400 words for standard pages; 800–1,500 for blog/resource content
- Include semantic keywords (related terms Google expects to see)
- Internal links: Link to 2–3 relevant pages on the site per piece of content

### Images:
- Alt text: Descriptive, includes keyword where natural
- File names: descriptive-keyword-name.jpg (not IMG_001.jpg)
- Compress all images — target under 200KB per image

### URL Structure:
- Short and descriptive: /services/brand-strategy/ not /services/page?id=23
- Include primary keyword
- Use hyphens, not underscores
- All lowercase

## 3. Technical SEO Audit Checklist

### Crawlability & Indexing:
- [ ] robots.txt exists and is not blocking important pages
- [ ] XML sitemap exists, is up to date, and submitted to Google Search Console
- [ ] No important pages returning 404 errors
- [ ] No redirect chains longer than 2 hops
- [ ] Canonical tags in place on duplicate or near-duplicate pages
- [ ] No noindex tags on pages that should be indexed

### Site Speed (Core Web Vitals):
- [ ] LCP (Largest Contentful Paint): Under 2.5 seconds
- [ ] FID / INP (Interaction to Next Paint): Under 200ms
- [ ] CLS (Cumulative Layout Shift): Under 0.1
- Tools: Google PageSpeed Insights, GTmetrix
- Common fixes: Image compression, lazy loading, caching, remove unused scripts

### Mobile:
- [ ] Site passes Google Mobile-Friendly Test
- [ ] No horizontal scrolling on mobile
- [ ] Tap targets (buttons/links) at least 48px
- [ ] Font size minimum 16px for body text

### HTTPS & Security:
- [ ] Site is fully HTTPS — no mixed content warnings
- [ ] SSL certificate valid and not expiring soon

### Structured Data (Schema):
- Add schema markup relevant to business type:
  - Local business: LocalBusiness schema
  - Articles/blog: Article schema
  - FAQs: FAQPage schema
  - Services: Service schema
  - Reviews: Review / AggregateRating schema

## 4. Local SEO (Singapore Focus)

Critical for SMEs and service businesses targeting local Singapore customers.

### Google Business Profile (GBP) Optimisation:
- [ ] Profile claimed and verified
- [ ] Business name exactly matches legal name (no keyword stuffing)
- [ ] Category: Primary category is most specific match; add secondary categories
- [ ] Address: Accurate, consistent with website and all directories
- [ ] Phone: Local Singapore number (+65)
- [ ] Hours: Accurate and updated for public holidays
- [ ] Website: Link to correct landing page (homepage or location page)
- [ ] Description: 750 chars. Natural keyword inclusion. No links or promotional language.
- [ ] Photos: Minimum 10 photos — exterior, interior, team, work/products
- [ ] Posts: Update GBP posts weekly — events, offers, news

### Review Strategy:
- Ask every satisfied client for a Google review — provide a direct link
- Respond to every review (positive and negative) within 48 hours
- Never incentivise reviews — against Google policy

### Local Citations:
Ensure NAP (Name, Address, Phone) is consistent across:
- Google Business Profile
- Facebook Business Page
- LinkedIn Company Page
- Yelp Singapore
- Yellow Pages Singapore
- Industry-specific directories

## 6. SEO Reporting

### Monthly SEO Report Structure:
1. **Rankings Summary** — Position changes for top 20 target keywords
2. **Organic Traffic** — Sessions, users, trend vs. last month and YoY
3. **Top Landing Pages** — Which pages are driving the most organic traffic
4. **Technical Health** — Any new crawl errors, Core Web Vitals changes
5. **Wins This Month** — Pages that improved, new keywords ranking
6. **Issues to Address** — Priority technical or content fixes
7. **Next Month Focus** — Top 3 priorities

### Core SEO Metrics to Track:
| Metric | Tool | Target Trend |
|---|---|---|
| Keyword rankings | Google Search Console / SEMrush | Up |
| Organic sessions | Google Analytics | Up |
| Click-through rate | Google Search Console | Up |
| Core Web Vitals | Search Console / PageSpeed | Green / Pass |
| Backlinks | Ahrefs / Search Console | Growing |
| Indexing errors | Search Console | Down to zero |
